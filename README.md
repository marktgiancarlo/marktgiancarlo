# Mark Giancarlo

I'm working through a self-directed master's-level program in cybersecurity, built entirely on free resources. It focuses on securing mainframe systems (z/OS, RACF, CICS) and cloud platforms (AWS, Azure), and on the modernization path between them.

This profile collects hands-on mainframe work, one project per repo.

## Portfolio

| Project | What it shows |
|---|---|
| [zos-jcl-utilities](https://github.com/marktgiancarlo/zos-jcl-utilities) | JCL jobs using IEBGENER, IEBCOPY, IDCAMS and SORT, plus a cataloged procedure with symbolic parameters, with notes on each dataset type used |
| [cobol-vsam-update](https://github.com/marktgiancarlo/cobol-vsam-update) | A COBOL batch program that reads a sequential file, updates a VSAM KSDS and writes a report, with its compile-and-run JCL |
| [rexx-dataset-report](https://github.com/marktgiancarlo/rexx-dataset-report) | A TSO REXX script that lists datasets matching a pattern and reports their space usage and last-referenced dates |

## Focus areas

- **Mainframe:** z/OS, JCL, COBOL, VSAM, REXX, TSO/ISPF
- **Mainframe security:** RACF, CICS
- **Cloud security:** AWS, Azure
- **Modernization:** connecting mainframe and cloud environments securely
